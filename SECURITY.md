# Politique de sécurité

Ce projet traite des données personnelles sensibles. Merci de signaler toute vulnérabilité **de façon privée**.

## Signaler une vulnérabilité

- Utiliser le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.
- Ne pas ouvrir d'issue publique, ne pas publier de preuve d'exploitation, ne pas accéder aux données d'autres personnes au-delà du strict nécessaire pour démontrer le problème.

Nous accusons réception sous 72 heures et tenons la personne qui signale informée jusqu'à la correction.

## Périmètre

Tout le code de ce dépôt et les environnements de l'association. Les tests intrusifs (déni de service, ingénierie sociale, tests sur des comptes réels) sont exclus, sauf dans le cadre du bug bounty interne annoncé avant le lancement (voir `docs/07-confiance-securite.md`).
